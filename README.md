# Smriti React Portfolio

A responsive portfolio website built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Customize

Edit `src/main.jsx` to change:
- About text
- Skills
- Projects
- GitHub / LinkedIn links
- Email address

Edit `src/styles.css` to change colors, typography and layout.
